# Pac-Man (1980) Recreation

A faithful recreation of the 1980 arcade Pac-Man, built with vanilla HTML5 Canvas and JavaScript (ES modules), with no libraries or build tools.

This is a learning project for my IITC course.

## How to run
1. Open the project folder in VS Code.
2. Right-click `index.html` and choose **Open with Live Server**.

ES modules need a local server, so opening the file directly (`file://`) won't work.

## Reference
Game rules follow **"The Pac-Man Dossier"** by Jamey Pittman.
